# Пакет публичных историй

Этот раздел описывает будущий обмен историями между RPKB и сайтом. Синхронизация кейсов не настроена и не запущена. Еженедельной сверки и сигнала после слияния PR нет.

Публикация самих страниц сайта от этой автоматизации не зависит. Ветка `main` выкладывает собранный сайт после проверок. Когда заработает пакет историй, новые сессии будут попадать в репозиторий без ручного переноса. До этого тексты шести страниц пишутся и выпускаются отдельно.

Роман передаёт сведения в RPKB. После подтверждения фактов и разрешения публичной редакции сайт должен принимать уже отобранный пакет, а не читать приватный канон.

## Кто за что отвечает

- RPKB хранит канон, публичные редакции, разрешения и полный реестр происхождения.
- Внутренний агент RPKB замечает подходящие материалы и готовит публичную редакцию. Отбор идёт по связям и типам записей, не по слову «стратсессия».
- Сервис синхронизации, когда его отдельно согласуют, собирает версионированный пакет только разрешённых данных и сверяет его с последним успешно доставленным пакетом. Пропуск одного запуска не отменяет следующее обновление.
- Репозиторий сайта принимает пакет и показывает его существующими шаблонами. Доступ ко всему приватному RPKB ему не нужен.

Полное соответствие источникам остаётся в RPKB. В сайт попадают безопасные тексты, разрешённые медиа и идентификатор версии пакета.

## Что уже есть в репозитории

- Контракт и проверки: `src/content/public-package.ts`.
- Принятые истории: `src/content/delivered-cases.json`. Сейчас список пуст.
- Редакционный выбор главной: `src/content/editorial.json`. Импорт его не перезаписывает.
- Очередь подготовки и отметка выпуска: `content/import-state.json`. Очередь не показывается посетителю и не входит в страницы.

Команда `npm run import:package -- --package <файл>` применяет один уже собранный пакет. Она не ходит в RPKB. `npm test` проверяет правила импорта. `npm run check:package` проверяет файлы, которые уже лежат в репозитории.

## Запись истории

У истории постоянный `id`. Он не меняется между редакциями. `contentVersion` меняется, когда меняется разрешённый текст.

Назначение — одно из значений: `corporate-work`, `personal-program`, `practice`. Формат — одно из значений: `corporate-session`, `unit-preparation`, `audit`, `foresight`, `accompaniment`. Формат не выводится из названия и не переименовывается.

Подборки записи: `corporate` и `cases`. Попадание на главную сюда не входит. Его задаёт только `featuredIds` в редакционном файле, не больше трёх историй. Поле выбора в пакете считается лишним, и такой пакет отклоняется.

Разрешённые медиа лежат в `/assets/cases/` и имеют текстовую подпись. Внешние и дисковые ссылки пакет отклоняют.

В пакете нет цен, продуктовых обещаний, путей канона и реестра разрешений. Эти поля нельзя добавить под другими именами: неизвестное поле отклоняет пакет целиком.

## Импорт

Пакет применяется целиком или не применяется.

- Тот же идентификатор и та же версия текста не создают вторую карточку. Повтор той же версии с другим текстом отклоняется.
- Новая разрешённая версия заменяет прежний публичный текст. Выбор для главной остаётся редакционным.
- Нет публичной редакции — стадия «обнаружено», история в очереди, на сайт не ставится.
- Редакция есть, разрешения нет — стадия «подготовлено», история в очереди. Прежний разрешённый текст остаётся, новое разрешение само не возникает.
- Истории нет в новом пакете — это не снятие. Снятие требует непустого основания и полного пакета.
- `complete` не равен `true`, пакет повреждён или не читается — доставленные истории и очередь не меняются.
- Успешный импорт отмечает пакет как доставленный в репозиторий. Отметку выпуска он не ставит и файлы цен, текстов страниц и вёрстки не трогает.

Стадии ведутся раздельно: обнаружено, подготовлено, доставлено в репозиторий, опубликовано. Последняя стадия остаётся пустой, пока выпуск не согласован отдельно. Ошибка оставляет очередь и последнюю принятую версию историй.

Автоматический выпуск, если его позже разрешат, касается только уже проверенных историй. Дизайн, код, цены и продуктовые обещания в него не входят.
